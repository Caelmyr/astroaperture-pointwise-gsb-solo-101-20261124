# AstroAperture｜星野测光

在一张已经校正的线性灰度星野图上，标记目标星、比星与天空背景中的干扰。工作台根据孔径测出净光，引用已知比星星等求目标星等，并保存观测。

在本目录运行 `./start.sh`，打开 [星野测光](http://127.0.0.1:19904/)。设置 `ASTRO_PORT` 可改本地端口。`./start.sh stop` 停止服务并保留数据卷。也可在虚拟环境按 `requirements.txt` 安装，再以 `python -B -m astro` 启动。

1. 导入单幅线性 16 位灰度 PNG 或 TIFF。可直接打开内置练习星图，星点、背景渐变和热像素均由程序模拟。
2. 拉伸显示黑白点，切换饱和标记，查看原片像素直方图。所有定量读数来自 16 位数据。下载的 PNG 保持工作坐标和 16 位像素数值。
3. 在图上点星标记中心，修改孔径和天空环的半径，指定目标、比星或校验用途。比星需要输入目录星等。重定位中心用当前孔径附近的亮度重心。
4. 为天空环中的邻星或瑕疵标记排除圈。检查净光、天空中位、有效像素数、峰值和原像素横竖剖面，结合增长曲线调整星点孔径。
5. 差分面板列出各比星独立得出的目标星等，汇总为各有效结果的中位数，并列出有效比星数和离散范围。孔径越界、饱和、天空采样不足或净光不为正会显示原因。
6. 保存本次观测，从记录列表重开原片修订和测光结果，下载含孔径与排除圈的 JSON 或比星表 CSV。观测保存后，进一步调整工作台标注还可回查旧读数。
7. 需要比较显示、校准与准备方案时，可以把原片复制到照片准备工作区。准备区的预览或输出有自己的成像设置，测光台保留原片的定量数据和出处。

图像最多 20 MiB，边长 32 至 4096 像素，最多 420 万像素。每张原片最多 30 个孔径、24 个排除圈。上传只接收已转成线性灰度的定标原片。坐标按转正后的像素中心计，左上第一个像素为 (0, 0)。星下天空估计默认使用圈内有效像素的中位数。净光中的天空波动估值用于现场参考，目录零点、传感器增益和色项需按观测条件另行校准。演示数据用于练习操作。
